## How to Reproduce

### Test 1 — Sensor throughput

```bash
# Start the stack
tilt up  # or: docker compose up -d mosquitto collection-db collection-service

# Scenario A — 600/hour
docker compose run -d -e Devices=10 -e interval=60 --name sim-a collection-simulator
# wait 2+ minutes, then stop:
docker stop sim-a

# Scenario B — 3 000/hour
docker compose run -d -e Devices=50 -e interval=60 --name sim-b collection-simulator
docker stop sim-b

# Scenario C — 36 000/hour
docker compose run -d -e Devices=60 -e interval=6 --name sim-c collection-simulator
docker stop sim-c

# Monitor while running
docker compose logs -f collection-service --tail 0 | grep -E "processing|warn|drop|error"
docker stats collection-service collection-db mosquitto --no-stream
```

### Test 2 — HTTP baseline (10 VUs, 3 min)

```bash
k6 run \
```

### Test 3 — Concurrent users (ramp to 1 000 VUs, 10 min)

```bash
k6 run \
  --env K6_USERNAME=admin@innoveria.dev \
  --env K6_PASSWORD="<password>" \
  --env BASE_URL=http://localhost:8081 \
```

**VU ramp stages:**
```
0 → 300 VUs  over 2 min   (validates Req 1)
300 → 600    over 2 min   (2× headroom)
600 → 1 000  over 2 min   (stress ceiling)
hold 1 000   for 3 min
ramp down    over 1 min
```
